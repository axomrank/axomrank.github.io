# Axomrank · Assam government exam preparation

Short, bilingual (English and Assamese) lessons and exam practice for ADRE, Assam TET, APSC and Assam Police SI. It works offline and can be installed from the browser.

**Live:** https://axomrank.pages.dev (also https://axomrank.github.io/)


## Adding a lesson

1. Write `content/lessons/<id>.json` (`suteuphaa.json` and `subinphaa.json` are models) following [docs/LESSON-DESIGN.md](docs/LESSON-DESIGN.md). Give every step a unique, permanent `id`.
2. Put images in `content/media/<id>/`; add new names to `content/entities.json`.
3. Add the lesson to its course outline in `content/courses/` and its exam questions to `content/questions/`.
4. Run `scripts/verify.sh`, then publish (see [docs/SETUP.md](docs/SETUP.md)).

Mathematics is different: change its generator, not the JSON. See [docs/MATHEMATICS-COURSE.md](docs/MATHEMATICS-COURSE.md).

## Working on the experience

Read [the revamp plan](docs/EXPERIENCE-REVAMP.md) before changing the player or lesson structure. Published lesson and exercise ids are permanent because saved progress and review use them. A current daily memory mission opens up to eight due questions; the remaining queue is kept for optional later rounds. The planned fact model will add stable fact links alongside existing question ids and will distinguish completion from recall after a delay.

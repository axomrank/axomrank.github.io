# Assamese Language course plan

Status: not ready to schedule. Nothing is built, and the need has not been measured.

## Why it is unmeasured

The `PYQ` set extracts only English text, so language papers are missing from every count in
the roadmap. It records that Part V of the 2021 Special TET Paper I, questions 121 to 150, is
an optional Language-I section in nine languages, and those 30 questions are not included.
TET therefore does test language. Nothing here shows how much ADRE, APSC or Police ask.

The Assamese version of this section may be one of the most useful courses for this
audience, so it should be measured rather than skipped.

## First step: measure it

1. Read the Assamese Language-I section of the TET booklets from the page images, because
   the text layer does not extract Assamese.
2. Check each current exam's syllabus for an Assamese language paper or section.
3. List topics and counts here, and add them to the roadmap.

The topic list must come from that reading. This plan does not guess it.

## What is already known

- **Course id:** `assamese-language`, with lesson ids `as-NN-slug`, if it goes ahead.
- **Author:** this course needs a fluent Assamese writer and a language teacher to set the
  content. AI-written Assamese prose elsewhere in the app is pending editorial review, which
  is a poor footing for a course about correct Assamese. This course should not be drafted
  first and reviewed later.
- **Questions:** must be original. Do not copy examples from grammar books.
- **Input:** Assamese typed answers would need a new keypad, as letter answers did in
  Reasoning. Tap-based steps avoid that at first.
- **Script:** Assamese-specific letters such as ৰ and ৱ must not be replaced with Bengali
  forms. Check rendering on modest Android phones.

## Decision needed

After the measurement, the course owner decides whether it goes ahead and who writes it.

# Constitution locator maps

Added on 2026-11-05. The 11 WebP assets in `content/media/constitution/maps/` serve 17 story cards. The inventory lists the exact card IDs. The separate rendered map in lesson 46 remains in use.

| Local source | Reuse and attribution |
|---|---|
| `../Assam History/data/maps/world.json` | Generalised base outlines on all new maps. Natural Earth 1:10m Admin 0 Countries, public domain. |
| `../MAP/data/maps/northeast.json` | Statehood, border, Gauhati jurisdiction, Sixth Schedule and special provisions maps. DataMeet Community Maps, States/Admin2, CC BY 4.0 / ODbL as documented by the source dataset. State outlines are redrawn and colour coded. |
| `../MAP/data/maps/bengal-districts.json` | Berubari vicinity. Jalpaiguri uses DataMeet Census 2011 districts, CC BY 4.0 / ODbL. Panchagarh uses BBS/OCHA districts via geoBoundaries gbOpen ADM2, CC BY 3.0 IGO. |
| `content/maps/assam.json`, `content/entities.json` | Nagaon and Karbi Anglong locator uses the existing project district layer and Nagaon point. The upstream district KMZ licence is unrecorded. |
| `../Constitution sources/constitution-of-india-2026-en.pdf` | First Schedule, Sixth Schedule paragraph 20 table, Articles 371A–371H, and Appendix I. Appendix I locates Berubari in the Panchagarh–Jalpaiguri area. |
| `../MAP/research/colonial-stages-2026-11-04/statehood-guide.md` | Northeast statehood context. The map uses modern outlines and the lesson supplies the sequence. |

Pins are approximate reference locations. The Berubari image locates the district pair. The Bangladesh image locates the border region. Neither depicts a surveyed transfer line. The 1956 cards use a modern India reference outline, and the 2019 Jammu and Kashmir card locates Srinagar and Leh using pins. Sixth Schedule state shading identifies the four states containing areas under the Schedule. It does not trace council boundaries. Assamese captions are pending editorial review.

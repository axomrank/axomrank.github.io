## Course promise

Learners build a mental atlas of Assam and use it to explain a real pattern or
defend a decision from map evidence. The core suits beginners and general
exam preparation. Examples span both valleys and the uplands. District
inventories, exhaustive tributary lists, production rankings and detailed
geology belong in optional references outside the timed path.

## Unit sequence

The right column names the signature task in each unit. Fill out the remaining
practice with retrieval, interpretation and misconception checks under the
[lesson design contract](LESSON-DESIGN.md).

| Unit | Story beat | Signature practice |
|---|---|---|
| 1.1 | Find Assam on a Northeast India locator | Tap Assam, then use compass directions to identify a neighbour |
| 1.2 | Zoom from the border to the two valleys | Place each valley on an unlabelled outline |
| 1.3 | Cross the uplands between valley plains | Match terrain profiles to the Karbi Anglong plateau and Dima Hasao hills |
| 1.4 | Orient yourself using cities | Place Guwahati, Dibrugarh and Silchar, then infer a relative direction |
| 2.1 | Follow the Brahmaputra through Assam | Order selected places along a flow arrow |
| 2.2 | Watch tributaries join the main channel | Locate selected confluences and identify bank side facing downstream |
| 2.3 | Follow the Barak across the southern valley | Match a small set of rivers to their drainage system |
| 2.4 | Infer where runoff goes | Read a simple ridge-and-stream diagram and choose the receiving river |
| 3.1 | See water spread across a floodplain | Compare normal and high-water images using the same extent |
| 3.2 | Find where a riverbank moved | Spot a change in two dated images and distinguish erosion from inundation |
| 3.3 | Read a flood-hazard map | Match legend classes to locations and explain what the observation period means |
| 3.4 | Compare exposure across the floodplain | Use the same legend to compare a settlement, a field and a road |
| 4.1 | Read one year or a climatology of rainfall | Read a labelled monthly chart and compare seasons |
| 4.2 | Follow water into a wetland | Match photo and map clues to river channel, wetland and upland |
| 4.3 | Compare contrasting habitats | Match habitat evidence to selected protected sites |
| 4.4 | Locate conservation sites on the atlas | Place a small set such as Kaziranga, Manas and Deepor Beel, subject to source checks |
| 5.1 | Compare two farming landscapes | Use a sourced table and terrain clues to compare selected rice and tea examples |
| 5.2 | Follow oil from production to processing | Match a selected field and refinery to their roles |
| 5.3 | Follow goods across the state | Order legs of a documented road, rail or water route |
| 5.4 | Explain a settlement pattern | Choose two independent clues from terrain, routes and crossings |
| 6.1 | Open a fictional market-siting case | Read the map layers and identify the two sites |
| 6.2 | Compare the candidates | Sort evidence under access and flood exposure |
| 6.3 | Make and defend a choice | Apply a stated priority, choose a site and match two supporting observations |

Each lesson test samples the current mission and at least one earlier idea
where available. The case test presents a second schematic with explicit
decision criteria and an answer determined by the evidence. The final atlas
reconstruction pairs the four baseline skills with four fresh prompts. Report
first-attempt location, interpretation and explanation scores separately.

## Authoring and implementation

- Plan for 23 units, 46–69 story cards and 115–161 unit exercises, plus six
  short tests, the baseline and final reconstruction. Give each unit four
  learned points, including meaningful retrieval of earlier material.
- Write English and Assamese together. Keep an agreed bilingual glossary for
  map labels, drainage terms and place-name variants. Mark new Assamese prose
  pending editorial review.
- Reuse the existing map, picture, match, order, spot and true/false formats.
  Use static maps or charts for evidence and split a multi-part explanation
  into short existing interactions. Check map targets on small screens and
  supply readable legends and text equivalents for essential evidence.
- Use a private draft course and existing lesson paths and mission metadata.
  Represent the atlas through map views and findings across the lessons.
  Use the linked atlas worksheet for the opening, final and later memory
  checks. The worksheet supplies a shared skill rubric and manual scoring.
- Give every assessed prompt a permanent step ID. Maintain a source and skill
  crosswalk for later review variants. Use existing step-based spaced review
  where available. For the pilot, separately schedule five-minute fresh-cue
  checks on days 1, 3 and 7. Count first attempts only and report delayed
  recall separately from completion and same-day accuracy.
- Keep five-item lesson tests within their five-minute slot at target pace.
  Test the existing 80% first-attempt gate. Checkpoint and test-out questions
  have no retries. Ordinary practice follows the existing retry rules.
  Report the observed time for learners who need extra attempts.
